                           GUIA DE LEVEL DESIGN (PERSPECT)
================================================================================

COMO FUNCIONA:
- O TOPO do arquivo é o CÉU.
- O FUNDO do arquivo é o CHÃO (Y = 0).
- O Jogo usa um "Grid de Profundidade" dividido em 3 Fatias (Fundo, Meio, Frente).

--------------------------------------------------------------------------------
1. BLOCOS ESTRUTURAIS (PAREDES ESTÁTICAS)
--------------------------------------------------------------------------------
[#]  CHÃO SÓLIDO (Cinza)
     - Profundidade Total (100%). Seguro em qualquer modo.

[M]  MEIO (Azul)
     - Ocupa Fundo + Meio (66%).
     - Cria um degrau visual.

[F]  FUNDO (Laranja)
     - Ocupa apenas o Fundo (33%).
     - PERIGO: No modo 2D (Z=0), o jogador CAI se tentar andar aqui.
     - Requer modo 3D ('C') e tecla 'W' (fundo) para pisar.

--------------------------------------------------------------------------------
2. PLATAFORMAS MÓVEIS
--------------------------------------------------------------------------------
[H]  PLATAFORMA HORIZONTAL (Azul Claro)
     - Move-se para Esquerda/Direita (3 blocos).
     - Carrega o jogador. Útil para cruzar abismos reais.

[V]  PLATAFORMA VERTICAL (Roxo Claro)
     - Move-se para Cima/Baixo (4 blocos).
     - Funciona como elevador.

--------------------------------------------------------------------------------
3. MOEDAS NO AR (CONTROLE DE PROFUNDIDADE)
--------------------------------------------------------------------------------
[o]  MOEDA NORMAL (Meio): Z = 0.0. Pegue andando.
[-]  MOEDA DE FUNDO (Back): Z = -3.33. Vá para o fundo pegar.
[+]  MOEDA DE FRENTE (Front): Z = +3.33. Venha para frente pegar.

--------------------------------------------------------------------------------
4. COMBOS (PAREDE + MOEDA)
--------------------------------------------------------------------------------
[$]  COMBO FUNDO (Parede F + Moeda Meio)
     - Cria Parede Laranja [F] + Moeda no caminho do Player (Z=0).
     - ARMADILHA: A moeda atrai o jogador, mas o chão [F] está no fundo.
       Se o jogador pular na moeda sem mudar para 3D e ir para o fundo, ele cai no vazio.

[%]  COMBO MEIO (Parede M + Moeda Frente)
     - Cria Parede Azul [M] + Moeda na Frente (Z=+3.33).
     - A moeda flutua "fora da tela". Exige 3D para visualizá-la e coletá-la.

--------------------------------------------------------------------------------
5. INTERATIVOS BÁSICOS
--------------------------------------------------------------------------------
[P] Start    [@] Vitória    [X] Caixa    [_] Placa de Pressão
